# Local Phase 2 Training

Этот скрипт (`train_phase2_local.py`) предназначен для **локальной обкатки** и отладки обучения декодера Phase 2 без использования XLA, TPU и распределенного обучения. Он вычисляет тензоры на классическом CPU/GPU через стандартный PyTorch.

Идеально подходит для быстрой проверки гипотез (например, работы `attention_mask` или новой функции потерь) без траты драгоценной квоты на Kaggle/GCP.

## Быстрый запуск

Убедитесь, что активировано виртуальное окружение, и запустите команду из корня проекта:

```powershell
.venv\Scripts\python.exe "experiments\phase 2\local\train_phase2_local.py" --data_path "experiments\phase3\kaggle\kaggle_dataset\phase 3\train_data\data"
```

*(Замените `--data_path` на актуальный путь к вашим `.parquet` файлам, если они были перемещены).*

## Ключевые параметры (Аргументы)

Скрипт поддерживает гибкую настройку через аргументы командной строки. По умолчанию выставлены безопасные "щадящие" значения, чтобы не вызвать переполнение оперативной памяти на обычных ноутбуках.

| Аргумент | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--data_path` | `..\..\..\experiments\phase 3\train_data\data` | Папка с обучающими `*.parquet` датасетами. |
| `--batch_size` | `2` | Размер батча. Не рекомендуется поднимать выше 4 при локальном запуске. |
| `--max_length` | `128` | Максимальная длина последовательности (в токенах). |
| `--max_steps` | `2000` | Жесткий лимит шагов обучения. |
| `--save_every` | `500` | Интервал (в шагах) между локальными сохранениями весов. |
| `--ckpt_dir` | `./checkpoints` | Папка для сохранения `.pth`, `.csv` логов и `.png` графиков. Создается автоматически. |
| `--phase2_resume_ckpt`| `""` (пусто) | Путь к чекпоинту Phase 2. Если указан, скрипт подгрузит веса, историю лосса и счетчик шагов. |

## Особенности реализации
1. **Экономия RAM:** Используется `torch.autocast(dtype=torch.bfloat16)` для уменьшения потребления памяти в два раза.
2. **Отсечение лишнего:** Массивная часть модели Qwen удаляется из памяти сразу после инициализации (`gc.collect()`), оставляются только нужные матрицы эмбеддингов (`embed_tokens` и `lm_head`).
3. **Авто-Графики и Логи:** На каждом шаге `save_every` скрипт автоматически строит график лосса (`.png`), сохраняет CSV-лог и веса (`.pth`).
4. **Умная ротация:** Скрипт сохраняет только 4 последние версии чекпоинтов и графиков, чтобы не забивать жесткий диск, а также ведет непрерывный файл `loss_log_current.csv`.
