2. Эмпирические данные: это не просто гипотеза

Вы спросили: «Ты видишь рост scale именно в этом месте? Или это гипотеза?»

Я написал скрипт, извлекший веса `adaLN` прямо из вашего чекпоинта `17995.pth`. Вот факты:

Layer 00 | shift_bias mean: 0.0000 | scale_bias mean: 0.9921
Layer 39 | shift_bias mean: 0.0000 | scale_bias mean: 0.9921

Overall Avg Scale Bias: 0.9921 (инициализация была 1.0)

Вывод: Сеть полностью проигнорировала t_emb (веса t_emb равны 0). Более того, scale ушел в константу 0.992. Почему при scale < 1 норма выросла? Ответ кроется во взаимодействии Pre-LN и Residual Stream.

3. В чем точная причина сбоя? (LayerNorm Erasure)

Текущая реализация применяет AdaLN как `forward_pre_hook`. Это означает, что умножению на scale подвергается сам Residual Stream перед тем, как войти в трансформерный слой (ModernBERT использует Pre-LN).

Residual
Stream (x)
→
AdaLN (Hook)
x_scaled = x * scale
→
LayerNorm
LN(x_scaled) == LN(x) !
→
Attention

Поскольку LayerNorm(x * scale) = LayerNorm(x) (Scale-Invariant property), слои Attention и MLP вообще не видят вашего кондиционирования t!
Они полностью «глухи» к диффузии. Сеть пытается выполнить задачу шумоподавления без знания уровня шума.

Единственное, на что влияет AdaLN сейчас — это сам Residual канал. Умножение на 0.992 (векторно по каналам) искажает изотропию канала на каждом слое. Пытаясь пробить сигнал сквозь 40 слоев, модель раздувает апдейты Attention/MLP, что ведет к тому, что norm_Llast разгоняется до 1500+ и происходит срыв градиентов.

4. Как это исправить? (Правильный DiT-паттерн)

Чтобы AdaLN работал, он должен модулировать сигнал после LayerNorm, но до Attention/MLP, и ни в коем случае не должен умножать сам Residual Stream.

Residual
Stream (x)
→
LayerNorm
x_norm = LN(x)
→
AdaLN
x_mod = x_norm * scale + shift
→
Attention
→
+ Residual
x + Attn(x_mod)

Решение в коде:

// Убрать forward_pre_hook для всей модели.
// Вместо этого нужно пропатчить ModernBertLayer или использовать хуки сложнее:

def patch_modernbert_layer(layer, adaln_module):
    original_forward = layer.forward
    def new_forward(hidden_states, *args, **kwargs):
        residual = hidden_states
        
        # 1. Применяем стандартный LayerNorm
        normed = layer.attn_norm(hidden_states)
        
        # 2. Модулируем AdaLN! (t_emb передаем через глобальную переменную или args)
        shift, scale = adaln_module(current_t_emb)
        normed = normed * scale + shift
        
        # 3. Внимание
        attn_output = layer.attn(normed)
        hidden_states = residual + attn_output
        ...
        // То же самое для MLP блока

Только так диффузия (параметр t) попадет внутрь логики сети, а Residual Stream останется чистым (identity), что не позволит норме взорваться!
