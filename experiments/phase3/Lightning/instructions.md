# Инструкции по работе с Lightning AI Studio

Этот документ содержит ключевые нюансы и лучшие практики по использованию облачных GPU инстансов от Lightning AI для обучения моделей проекта BEBLaDII.

## 1. Выбор шаблона и базовые настройки
- **Шаблон:** При создании новой Studio (New Studio) всегда выбирайте шаблон **AI Development**. Он содержит предустановленный PyTorch, драйверы CUDA и настроен для задач Deep Learning.
- **Окружение (venv):** В Lightning AI Studio среда уже изолирована (по сути, это Docker-контейнер). Вам **не нужно** создавать локальную папку `.venv`. 
- **Установка зависимостей:** Проект управляется через `pyproject.toml`. Для установки всех библиотек просто выполните в корне проекта:
  ```bash
  pip install -e .
  ```

## 2. Стратегия экономии квот (Важно!)
Вам доступно 80 бесплатных часов на инстансе **T4** (16GB VRAM) в месяц. Квота тратится за каждую минуту *аптайма* машины, независимо от того, загружена видеокарта расчетами или нет.
- **Для настройки окружения, написания кода и скачивания репозитория (`git pull`)** — всегда переключайте машину на **CPU (Free)**.
- **Для тестовых и боевых прогонов обучения** — переключайте машину на **T4** (или A100/L40S для коротких тяжелых тестов). Переключение занимает пару минут и не удаляет ваши файлы.
- После завершения экспериментов не забывайте выключать студию (Stop Studio).

## 3. Пайплайн написания кода
Поскольку мы не используем Remote SSH/VS Code расширение (Local IDE), рабочий процесс выглядит так:
1. **Локально (Windows):** Пишете код, меняете логику и коммитите изменения.
2. **Локально (Windows):** Отправляете код в облако через `git push`.
3. **Lightning AI:** Открываете терминал Studio в браузере, делаете `git pull` и запускаете скрипт.

*Примечание:* Авторизация GitHub в Lightning AI нужна **только** если репозиторий приватный. Если он публичный — `git pull` работает из коробки.

## 4. Секреты и интеграции (GCS & W&B)
В интерфейсе Lightning AI (раздел Settings -> Environment Variables / Secrets) необходимо добавить два ключа:
- **`WANDB`** — содержит ваш токен авторизации Weights & Biases.
- **`GCP_STORAGE_API_KEY`** — содержит полный текст JSON-ключа от сервисного аккаунта Google Cloud.

*Как это работает:* Скрипт `train_phase2_decoder_lightning.py` автоматически прочитает эти переменные при старте. Токен W&B будет применен для логирования, а из текста GCP-ключа скрипт сам создаст временный файл `gcp_sa.json` внутри контейнера и авторизуется в GCS.

## 5. Возобновление обучения (Auto-Resume)
Сессии в Lightning AI ограничены 4 часами. Скрипт `train_phase2_decoder_lightning.py` специально адаптирован для этого:
- При запуске (флаг `resume_from_checkpoint = True`) скрипт автоматически сканирует бакет GCS, находит последний `.pth` чекпоинт, скачивает его и загружает в память.
- Чекпоинт теперь содержит не только веса декодера, но и стейты `optimizer`, `scheduler`, текущий `step` и `metrics_history`.
- W&B подхватит сессию, и графики продолжат рисоваться без разрывов, как если бы прерывания не было.

## 6. Запуск обучения
Когда всё готово (машина переключена на T4, зависимости установлены, ключи добавлены в настройки Студии), запуск производится командой:
```bash
python experiments/phase\ 2/Lightning/train_phase2_decoder_lightning.py
```
