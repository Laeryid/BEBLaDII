# Phase 6: Подготовка данных (Data Preparation)

Здесь фиксируются все примененные правила и нюансы при формировании обучающей выборки для Phase 6.

## Источник: Magpie-Reasoning-V2

- **Местонахождение исходных данных**: `C:\Experiments\BEBLaDII\data\magpie_reasoning\data\` (12 Parquet файлов, суммарно около 250k записей).
- **Структура**: Целевые поля — `instruction` (Вопрос/Промпт) и `response` (Ответ).
- **Правило извлечения ответа**: Ищется точное вхождение маркера `Final Answer` (или `**Final Answer**`). Извлекается весь текст после этого маркера.
- **Обработка отсутствия маркера**: Если маркер не найден, запись **полностью игнорируется** (пропускается). Эвристики (например, брать последний абзац) не применяются, чтобы не портить качество выборки случайными фрагментами текста.
- **Токенизатор**: `Qwen/Qwen2.5-7B-Instruct` (инициализируется через `src.beb_la_dii.utils.tokenizer.get_tokenizer()`). Совпадает по словарю с `Qwen2.5-1.5B`.
- **Фильтрация по длине**:
  - Минимальная длина финального ответа: 50 токенов.
  - Максимальная длина финального ответа: 500 токенов.
  - Усечение длины не производится. Если длина ответа выходит за пределы (50-500 токенов), запись целиком отбрасывается.
- **Формат результата**: Parquet. Поля — `Q` (Вопрос) и `A` (Ответ), а также `length`. Все записи собираются в единый файл `data_magpie.parquet`, который сохраняется в `C:\Experiments\BEBLaDII\BEBLaDII-planB-Phase6-Data\phase 6\train_data\data\`.
- **Итог**: Обработано 249 922 записей. Сохранено 10 266 (после фильтрации по минимальной/максимальной длине и строгому маркеру `Final Answer`).

## Источник: OpenThoughts-114k

- **Местонахождение исходных данных**: `C:\Experiments\BEBLaDII\data\open_thoughts\data\` (6 Parquet файлов, суммарно 113 957 записей).
- **Структура**: Целевое поле — `conversations` (список сообщений user и assistant).
- **Правило извлечения вопроса (Q)**: Берётся `value` из первого сообщения (роль `user`).
- **Правило извлечения ответа (A)**: Из второго сообщения (роль `assistant`) извлекается блок между тегами `<|begin_of_solution|>` и `<|end_of_solution|>`. Текст рассуждений между `<|begin_of_thought|>` и `<|end_of_thought|>` отсекается.
- **Обработка отсутствия маркера**: Если тег `<|begin_of_solution|>` отсутствует или решение пустое, запись отбрасывается.
- **Токенизатор**: `Qwen/Qwen2.5-7B-Instruct` (инициализируется через `src.beb_la_dii.utils.tokenizer.get_tokenizer()`).
- **Фильтрация по длине**:
  - Длина ответа: 50–500 токенов (строго без усечения).
- **Формат результата**: Parquet. Поля — `Q`, `A`, `length`. Сохраняется в единый файл `data_openthoughts.parquet` в `C:\Experiments\BEBLaDII\BEBLaDII-planB-Phase6-Data\phase 6\train_data\data\`.
- **Итог**: Обработано 113 957 записей. Сохранено 46 477 (после фильтрации по длине ответа 50–500 токенов и очистки от тегов рассуждений).
