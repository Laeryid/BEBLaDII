# Kaggle Notebook Generation Workflow

Для создания и редактирования Jupyter Notebooks (`.ipynb`) в этом проекте используется подход на основе `jupytext`. Это позволяет писать код в обычных `.py` файлах (которые легко читаются, версионируются и редактируются в IDE), а затем автоматически генерировать из них `.ipynb` для Kaggle.

## Инструкция по применению

1. **Создание исходного файла:**
   Создайте обычный Python-скрипт (например, `train_phase3_notebook.py`).

2. **Разметка ячеек:**
   Используйте специальные комментарии `jupytext` для разделения ячеек:
   - Для Markdown ячеек:
     ```python
     # %% [markdown]
     # # Заголовок
     # Текст описания...
     ```
   - Для ячеек с кодом:
     ```python
     # %%
     import torch
     print("Hello Kaggle")
     ```

3. **Конвертация:**
   Запустите команду из корня проекта для генерации `.ipynb`:
   ```powershell
   .venv\Scripts\python.exe -m jupytext --to notebook experiments/phase3/kaggle/train_phase3_notebook.py
   ```

Данный подход решает проблему невозможности прямого редактирования `.ipynb` файлов текстовыми агентами и является индустриальным стандартом.
