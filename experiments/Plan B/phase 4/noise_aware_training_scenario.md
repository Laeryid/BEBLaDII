# Сценарий обучения: Noise-Aware Context Trust (Phase 4)

## Цель

Научить модель, чтобы **уровень шума токена `t_i` определял его вес как источника контекста для соседей** через градиентный сигнал — без жёсткой математики на инференсе.

---

## Ключевая проблема и механизм решения

**Текущее состояние**: AdaLN модулирует LayerNorm перед QKV-проекцией, то есть K-векторы шумных токенов УЖЕ отличаются от чистых. Но градиент через `L_cosine` говорит только «предскажи правильно», не указывая, через КАКОЙ ключ внимания была допущена ошибка.

**Решение**: Добавить в лосс множитель, который УВЕЛИЧИВАЕТ штраф за ошибку на чистом токене пропорционально тому, насколько шумен его контекст. Тогда градиент потечёт по цепочке:

```
L_isolation → z_pred_i (clean) → attn_weights(i→j) → Q·K^T → K_j (AdaLN(t_j))
```

Модель получит прямой сигнал: «снизь вес `K_j`, который пришёл из шумного токена j».

## Часть 1: Конфигурации датасета

Каждый батч состоит из трёх типов примеров в заданной пропорции.

### Тип A: «Остров» (20%)

Два подтипа:

**A1 — Абсолютный якорь** (`t_global` любой):
- 1–3 токена с `t_i ∈ [0.0, 0.15]` — *истинные якоря*
- Все остальные токены: `t_j ∈ [0.7, 1.0]`
- Цель: якоря должны предсказываться правильно **несмотря на шумных соседей**

```python
def sample_island_absolute(B, T, device):
    t = torch.rand(B, T, device=device) * 0.3 + 0.7   # base: все шумные
    num_anchors = torch.randint(1, 4, (1,)).item()
    for b in range(B):
        anchors = torch.randperm(T, device=device)[:num_anchors]
        t[b, anchors] = torch.rand(num_anchors, device=device) * 0.15
    return t
```

**A2 — Относительный якорь** (`t_global` Высокий):
- 1–3 токена с `t_i ∈ [0.3, 0.5]` — *умеренные токены среди шума*
- Все остальные токены: `t_j ∈ [0.7, 1.0]`
- Ситуация: `Выс;Ср;Выс` из таблицы поведения
- Цель: умеренный токен выступает как **относительный якорь** — чище своего окружения и должен не поддаваться «заражению» от соседей

```python
def sample_island_relative(B, T, device):
    t = torch.rand(B, T, device=device) * 0.3 + 0.7   # base: все шумные
    num_anchors = torch.randint(1, 4, (1,)).item()
    for b in range(B):
        anchors = torch.randperm(T, device=device)[:num_anchors]
        t[b, anchors] = torch.rand(num_anchors, device=device) * 0.2 + 0.3
    return t
```

### Тип B: «Море чистоты» (20%)
- 1–3 токена с `t_i ∈ [0.7, 1.0]` — *шумные выбросы*
- Все остальные: `t_j ∈ [0.0, 0.2]`
- Цель: шумные выбросы должны **не влиять на уже чистые соседей**

```python
def sample_sea_of_clarity(B, T, device):
    t = torch.rand(B, T, device=device) * 0.2          # base: все чистые
    num_noisy = torch.randint(1, 4, (1,)).item()
    for b in range(B):
        noisy = torch.randperm(T, device=device)[:num_noisy]
        t[b, noisy] = torch.rand(num_noisy, device=device) * 0.3 + 0.7
    return t
```

### Тип C: «Смешанный» (60%)
- Текущая логика Phase 4 с иерархическим шумом (ADR 083)
- Без изменений

### Ограничения сэмплирования `is_false_confident`

> **Критическое правило**: ложно-уверенные токены создаются **только** при условии, что модель имеет реальный инструмент их детекции — достаточно чистый контекст. Создание `is_false_confident` при высоком `ctx_noise` лишено смысла: модель не может отличить ложный токен от истинного якоря в шуме.

```python
# is_false_confident создаётся ТОЛЬКО при:
# - средний уровень глобального шума: t_global ∈ [0.3, 0.7)
# - достаточно чистый контекст соседей: ctx_noise < threshold_ctx
can_be_false_confident = (
    (t_global >= 0.3) and
    (t_global < 0.7) and
    (ctx_noise < threshold_ctx)   # рекомендуемое значение: 0.4
)
```

Комбинация `Выс;Выс;Выс` **исключена из сэмплирования**: при полном отсутствии якорей задача структурирования латентного пространства переходит к CA_prompt слоям (Phase 4.2).

## Часть 2: Функции потерь

### L_weighted — взвешенный косинус (замена текущего L_cosine)

Чистые токены получают полный градиент, зашумлённые — пониженный:

```python
def l_weighted(z_pred, z_clean, t_reported, alpha=2.0):
    cos_per_token = (z_pred * z_clean).sum(dim=-1)   # [B, T]
    w = (1.0 - t_reported).pow(alpha)                 # [B, T], w≈0 при t=1
    loss = -(w * cos_per_token).sum() / (w.sum() + 1e-8)
    return loss
```

> **Параметр `alpha`**: 2.0 — квадратичное убывание веса. При `alpha=1` убывание линейное (мягче). Рекомендуется начать с 1.5 и повысить до 2.0 на этапе 2.

---

### L_isolation — штраф за контекстную коррупцию (новый)

Для каждого токена штраф за ошибку умножается на среднюю зашумлённость его соседей, взвешенный сигмоидной маской. Маска мягко охватывает как **абсолютные якоря** (малый `t`), так и **относительные якоря** (умеренный `t` в шумном контексте), не требуя жёсткого порога:

```python
def l_isolation(z_pred, z_clean, t_reported,
                beta=2.0, window=5, k=5.0):
    """
    z_pred, z_clean: [B, T, D] — нормированные на сфере
    t_reported:      [B, T]    — уровень шума каждого токена
    beta:            сила штрафа за шумных соседей
    window:          полуширина окна для подсчёта контекстного шума
    k:               крутизна сигмоиды (k=5 → мягкий переход вблизи t=0.5)
    """
    B, T, D = z_pred.shape
    cos_err = 1.0 - (z_pred * z_clean).sum(dim=-1)   # [B, T], 0=идеал

    # Скользящее среднее шума контекста (симметричное окно, reflect-паддинг)
    t_exp = t_reported.unsqueeze(1)                    # [B, 1, T]
    kernel = torch.ones(1, 1, 2 * window + 1,
                        device=z_pred.device) / (2 * window + 1)
    ctx_noise = F.conv1d(t_exp, kernel,
                         padding=window,
                         padding_mode='reflect').squeeze(1)  # [B, T]
    # Вычитаем вклад самого токена
    ctx_noise = (ctx_noise * (2*window+1) - t_reported) / (2*window)
    ctx_noise = ctx_noise.clamp(0, 1)

    # Мягкая маска: сигмоида с центром на 0.5
    # t≈0.05 → ≈0.92 (абсолютный якорь), t≈0.4 → ≈0.62 (относительный якорь),
    # t≈0.8 → ≈0.18 (шумный — почти не участвует)
    clean_mask = torch.sigmoid(-k * (t_reported - 0.5))  # [B, T]

    # Штраф: ошибка × (1 + beta × шум_соседей) × вес_токена
    penalty = cos_err * (1.0 + beta * ctx_noise) * clean_mask
    return penalty.mean()
```

**Итоговый лосс:**
```python
loss = l_weighted(z_pred, z_clean, t_reported, alpha=alpha) \
     + lambda_iso * l_isolation(z_pred, z_clean, t_reported, beta=beta)
```

## Часть 3: Curriculum (двухэтапный)

Переход между этапами выполняется **вручную** на основе наблюдаемой динамики `Context Isolation Score` и утилизации квоты Kaggle.

### Этап 1 — «Осознание» (первые ~5k шагов)

| Параметр | Значение |
|---|---|
| Типы батчей | 40% Остров + 40% Море чистоты + 20% Смешанный |
| `lambda_iso` | 0.5 |
| `alpha` (L_weighted) | 1.5 |
| `beta` (L_isolation) | 1.5 |
| Обоснование | Модель видит экстремальные конфигурации чаще — формирует базовое понимание, что шумный контекст вреден |

| Параметр | Значение |
|---|---|
| Типы батчей | 20% Остров + 20% Море чистоты + 60% Смешанный |
| `lambda_iso` | 0.3 |
| `alpha` (L_weighted) | 2.0 |
| `beta` (L_isolation) | 2.0 |
| Обоснование | Пропорции близки к реальному инференсу; усиленный `alpha` и `beta` удерживают изученное поведение |

## Часть 4: Диагностика в evaluate_phase4_checkpoints.py

### Context Isolation Score (CIS)

Добавить в БЛОК 3 проверку **контекстной изоляции**: взять чистый токен, запустить forward с шумными соседями и с чистыми — разница косинуса должна стремиться к нулю по мере обучения:

```
CIS = cos(pred|noisy_ctx, z_clean) - cos(pred|clean_ctx, z_clean)
```

Целевое значение: `< 0.05` (модель «не замечает» шум соседей при оценке чистого токена).

**Ориентиры для ручного управления curriculum:**
- `CIS > 0.20` — Этап 1 ещё не завершён
- `CIS ∈ [0.10, 0.20]` — допустимо переключаться на Этап 2
- `CIS < 0.05` — цель достигнута

## Ожидаемый эффект

```
До:  чистый токен в шумном контексте → модель тянет его к "галлюцинации соседей"
После: чистый токен в шумном контексте → модель сохраняет его значение
        шумный токен в чистом контексте → модель агрессивно денойзит, не "заражая" соседей
        умеренный токен в шумном контексте → выступает как относительный якорь
```

Градиент потечёт через AdaLN в K-векторы: модель научится кодировать в K «я шумный — не доверяй мне» через самообучение, а не через жёсткую математику.
