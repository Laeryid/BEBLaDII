# ADR 086: Type C Full Noise Range и ограничение t_global ≤ 0.99

## Context

В Curriculum Батчировании (ADR 085) тип батча **Type C** (60% батча) семплировал `t_actual` токенов в узком окне вокруг `t_global`:

```python
t_min_true = clamp(tg - 0.3, min=0.0)
t_max_true = clamp(tg + 0.3, max=1.0)
t_actual[i] = rand(T) * (t_max_true - t_min_true) + t_min_true
```

Анализ показал, что это создавало слепое пятно: при низком `t_global` (финал диффузии, t ≈ 0.1–0.3) максимально достижимый `t_actual` не превышал 0.4. Модель практически не видела сценарий "один сильно зашумлённый токен в почти чистом контексте" — именно тот кейс, который требует активного использования механизма внимания для восстановления смысла по соседям.

Более глубокий анализ показал, что ограничение нижней границы (`t_min = tg - 0.3`) при высоком `t_global` также неправомерно. В реальном инференсе с промптом, уже после первой итерации денойзинга, промпт-якорные токены могут быть проявлены до почти чистого состояния (t_actual ≈ 0), пока t_global ещё высокий. Сужение нижней границы исключало этот реалистичный сценарий из обучения.

Дополнительно: `t_global` мог достигать ровно `1.0`, что соответствует полному шуму без какой-либо семантической информации в векторе. Обучение на таких сэмплах бесполезно — восстановить из чистого шума невозможно.

## Decision

1. **Type C — полный диапазон [0, 1]:**
   Обе границы убраны. `t_actual` семплируется равномерно из `[0, 1]` независимо от `t_global`:
   ```python
   t_actual[i] = torch.rand(T, device=cpu_dev)
   ```
   Это соответствует реальной диффузии с промптом: в любой момент диффузионного процесса может присутствовать произвольное сочетание чистых (промпт-якорь) и зашумлённых (свободная генерация) токенов.

2. **Ограничение t_global ≤ 0.99:**
   После сэмплирования добавлен clamp:
   ```python
   t_global = t_global.clamp(max=0.99)
   ```
   Значение t=1.0 (чистый шум) исключено из обучения, так как при нём невозможно получить обучающий сигнал.

## Consequences

- Модель обучается на реалистичном распределении, соответствующем промпт-гайдед инференсу: промпт-якоря могут быть чистыми на любом шаге диффузии.
- Механизм внимания получает градиентный сигнал на задачу "использовать чистые соседние токены для восстановления сильно зашумлённого" — даже при низком t_global (финал диффузии).
- Вес `l_weighted = (1 - t_reported)^alpha` естественно ограничивает влияние экстремально зашумлённых токенов: их вклад в градиент мал, поэтому риск дестабилизации обучения низкий.
- Поведение Types A1, A2, B не изменено.
