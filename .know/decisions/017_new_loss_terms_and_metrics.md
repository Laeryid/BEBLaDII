# ADR 017: Новые слагаемые потерь и метрики (RKD и Norm Correlation)

## Context and Problem
Для качественной дистилляции рассуждений (Reasoning Distillation) Студенту необходимо не просто приближать отдельные выходные векторы Учителя, но и унаследовать топологическую структуру и геометрию его латентного пространства. 

Ранее применяемые метрики (косинусное сходство и выравнивание дисперсии/масштаба) работали на уровне индивидуальных токенов. Однако они упускали два важнейших свойства:
1. **Геометрия латентного пространства**: Взаимное расположение (углы и расстояния) различных токенов в последовательности друг относительно друга. Без этого Студент не понимает внутреннюю топологию смысловых связей в тексте.
2. **Амплитуда норм**: Динамика изменения нормы векторов токенов вдоль последовательности. Норма токена часто коррелирует с его информативностью и уверенностью модели.

Требовалось внедрить новые слагаемые потерь, которые форсируют топологическое выравнивание, не нарушая при этом жестких ограничений:
* **ADR-016**: Полный отказ от MSE (абсолютных координат) на промежуточных слоях.
* **XLA/TPU**: Совместимость со статическими графами (без динамических срезов).
* **Стабильность**: Предотвращение взрыва градиентов при сильном маскировании (паддинге).

## Decisions Made and Lessons Learned
Было решено добавить два новых масштабно-инвариантных слагаемых в `DistillationLoss`:
1. **Relational Knowledge Distillation (RKD)** — лосс попарного косинусного сходства токенов в последовательности.
2. **Norm Correlation Loss** — лосс корреляции Пирсона для норм векторов токенов.

### Реализация RKD (Топологическая структура)
Для сохранения взаимных расстояний токенов вычисляется матрица попарных косинусных сходств размера `(B, T, T)` через быстрое векторное умножение тензоров, нормализованных по $L_2$:
$$\mathbf{S} = \bar{\mathbf{H}} \bar{\mathbf{H}}^T$$
Для маскирования паддинга используется двумерная маска:
$$\mathbf{M}_{2d} = \mathbf{m} \otimes \mathbf{m}^T$$
Где $\mathbf{m}$ — одномерная `attention_mask` размера `(B, T)`. Разница между матрицами Студента и Учителя минимизируется по MSE только для активных токенов:
$$\mathcal{L}_{rkd} = \frac{1}{\sum \mathbf{M}_{2d}} \sum \left( (\mathbf{S}_{student} - \mathbf{S}_{teacher}) \odot \mathbf{M}_{2d} \right)^2$$

### Реализация Norm Correlation (Выравнивание норм)
Для выравнивания динамики амплитуды норм вычисляется норма векторов по последней размерности $D$, центрируется по оси $T$ с учетом `attention_mask` (корреляция Пирсона) и вычисляется косинусное сходство между Студентом и Учителем по временной шкале:
$$\mathcal{L}_{norm} = 1.0 - \text{CosineSimilarity}(\text{norms}_{student}^{centered}, \text{norms}_{teacher}^{centered})$$

### Извлеченные уроки и градиентный граф
- **Изоляция Учителя**: Учительские тензоры во всех новых лоссах принудительно отсоединяются от графа (`.detach()`), чтобы избежать обратного распространения градиентов в тяжелую модель-учитель.
- **Особенности PyTorch при нулевых весах**: В юнит-тестах проверялась изоляция градиентов Учителя (`t_state.grad is None`). Было обнаружено, что если тензор Учителя хотя бы раз участвует в вычислениях лосса (например, центрированного косинуса), то даже при умножении этого лосса на `cos_weight = 0.0`, PyTorch оставляет тензор в графе вычислений и возвращает градиент из всех нулей (`0.0`), а не `None`. Тесты были адаптированы под это поведение: `assert t_state.grad is None or torch.all(t_state.grad == 0.0)`.

## Impact
- **Положительные стороны**:
  - Студент теперь более точно перенимает геометрические соотношения понятий в последовательности (топологию латентного пространства). Это критично для последующих CA (cross-attention) слоев, принимающих смысловые векторы из mu-VAE.
  - Сохраняется масштабное поведение норм токенов, что предотвращает коллапс латентного пространства.
  - Метрики логируются раздельно по слоям (20, 30, 40) и суммарно.
- **Компромиссы**:
  - Дополнительные затраты памяти и времени на вычисление `torch.bmm` размера `(B, T, T)`. Для текущих размерностей $B=2, T=64$ это пренебрежимо мало, но для очень длинных контекстов может потребоваться оптимизация.
  - Во избежание градиентного перетягивания (tug-of-war) веса лоссов по умолчанию установлены консервативными: `lambda_rkd=0.01`, `lambda_norm=0.05`.
