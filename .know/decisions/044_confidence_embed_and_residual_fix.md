# ADR 044: Внедрение Confidence Embedding и устранение двойного Residual (Conditional Diffusion)

## Context and Problem
В процессе оптимизации Phase 3 (Logic & Denoising) были обнаружены два архитектурных дефекта, мешавших эффективной сходимости:

1. **Слепота к уровню шума (Missing Condition):** 
   DUS (Depth Up-Scaling) получал на вход только вектор `z_noisy`, но не имел информации о том, насколько этот токен зашумлен (значение `c_true`). Из-за этого модель не могла использовать дифференцированные стратегии (например, "оставить чистый токен без изменений" или "перезаписать полностью зашумленный токен") и была вынуждена неявно угадывать уровень шума по контексту, что сильно замедляло оптимизацию.

2. **Двойной Residual (Architectural Conflict):**
   Внешняя residual-связь `dus_final = last_hidden_state + z_noisy` дублировала внутреннюю остаточную связь (residual stream) самого трансформера ModernBERT, который по определению сохраняет сумму всех предыдущих слоев и входного эмбеддинга. 
   Математически это означало `dus_final ≈ (z_noisy + corrections) + z_noisy = 2 * z_noisy + corrections`. Чтобы просто вернуть исходный чистый вектор, сети приходилось тратить емкость на выучивание вектора `-z_noisy`, что блокировало быстрое падение `identity_penalty`.

## Decisions Made and Lessons Learned
1. **Confidence Additive Projection:** 
   Добавлен 2-слойный MLP-проектор (`confidence_proj`), проецирующий скалярную уверенность `c_true` в размерность 1024. Полученный вектор `c_embed` прибавляется к входам DUS. Для безопасного старта финальный слой инициализирован нулями (Zero-Init). Это сделало DUS полноценной Conditional Diffusion Transformer моделью.

2. **Устранение внешнего Residual:**
   Убрано ручное прибавление `z_noisy` к финальному выходу. Теперь `dus_final = safe_normalize(last_hidden_state)`.
   Для сохранения спасительного L2-штрафа на амплитуду предсказаний (см. ADR 043), дельта теперь вычисляется математически корректно: `dus_delta = last_hidden_state - z_noisy`.

## Impact
- **Позитивно:** Ускорение сходимости `identity_penalty` и `denoise_loss` благодаря устранению необходимости инвертировать двойной residual.
- **Позитивно:** Модель получила явный сигнал о том, какие токены нужно исправлять, а какие — не трогать.
- **Позитивно:** Архитектура стала концептуально чистой и выровнялась с лучшими практиками диффузионных систем (DDPM, DiT).
