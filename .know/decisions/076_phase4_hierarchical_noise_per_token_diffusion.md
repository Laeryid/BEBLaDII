# ADR 076: Phase 4a - Hierarchical Noise and Per-Token Diffusion

**Date:** 2026-08-28  
**Status:** Accepted  

## Context

После успешного завершения обучения на Phase 3 (каноническая диффузия с uniform `t` для всех токенов) мы переходим к Phase 4a. Основное ограничение Phase 3 заключалось в том, что модель не могла различать уровни шума для отдельных токенов, что делало невозможным обучение условному инпейнтингу (когда одни токены уже ясны, а другие зашумлены). 
Для корректной работы Оркестратора и будущей генерации нам необходим механизм, где модель будет оценивать контекст и степень "уверенности" каждого отдельного токена с учетом глобальной фазы.

## Decision

Мы внедрили механизм иерархического шума (Hierarchical Noise) в `train_phase4_notebook.py`. Ключевые изменения:

1. **Генерация Ложных Уверенностей (False Confident Tokens):**
   - Введен `t_global` ~ U(0, 1), управляющий "температурой" всего батча.
   - Вероятность появления ложно-уверенного токена: `p_false = t_global ** 1.5`.
   - Ложные токены зашумляются сильно (`t_actual` велико), но рапортуют о себе как о чистых (`t_reported` мало).

2. **Архитектурные изменения (AdaLN и t_proj):**
   - Утилиты `SinusoidalEmbedding` и `spherical_noise` были обновлены для поддержки 2D-параметра шума формы `[B, T]`.
   - Модуль `t_proj` разделен на три ветки:
     - `t_proj_global` — для `t_global` (инициализируется весами Phase 3).
     - `t_proj_token` — для `t_reported` (новый слой).
     - `t_joint_proj` — объединяет их конкатенацией (`dim * 2 -> dim`).
   - **Zero-Init Compatibility Trick:** слой `t_joint_proj` инициализирован таким образом, что `W = [0, I]`, а `bias = 0`. Это позволяет при старте пропускать только сигнал `t_global`, обеспечивая 100% эквивалентность поведения весам Phase 3 на первом шаге.

3. **Loss Function (Удаление Min-SNR):**
   - Min-SNR взвешивание полностью удалено (заменено на uniform `w=1.0`). Причина: в Phase 4 токены с высоким `t_actual` критически важны для обучения контекстному восстановлению, и их даунвейт приводит к появлению "мертвой зоны".
   - Метрики (`cos_sim_t_low`, `cos_sim_t_high` и др.) теперь рассчитываются на основе `t_actual`.

## Consequences

- **Positive:**
  - Модель научится адаптивному скептицизму: при высоком `t_global` она будет проверять `t_reported` каждого токена, опираясь на контекст соседей.
  - Сохранена полная совместимость с весами Phase 3, что позволяет начать обучение (fine-tuning) без потерь из-за архитектурных изменений.
- **Negative/Risks:**
  - Усложнение архитектуры `t_proj` добавляет новые параметры, которые нужно аккуратно прогревать (используется LR = 1e-5 для новых слоев, 2e-6 для DUS).
  - Смещение лосса без Min-SNR может потребовать тонкой настройки LR.
