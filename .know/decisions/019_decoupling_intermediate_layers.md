# ADR 019: Decoupling Intermediate Layers from Teacher Representations

## Context and Problem

В ходе анализа текущего запуска (Phase 1 Distillation, шаги 2.5k–9k) были выявлены следующие симптомы:

- `delta_cos_l20` ≈ 0 на протяжении всего запуска — слой 20 не усваивает reasoning-траектории учителя.
- `val/l40_cov_loss` экспоненциально растёт (2.5 → 12+) начиная с шага 6k.
- `val/l40_isotropy` достигла пика (~0.2) на шаге 6k и начала снижаться — признак начала коллапса размерностей.

При анализе причин стало ясно, что **архитектурная предпосылка привязки промежуточных слоев к учителю ошибочна**:

- В LLM (DeepSeek-R1/Qwen) глубина слоев — это постепенная абстракция одного токена от синтаксиса к семантике.
- В нашей архитектуре (Conditional Latent Diffusion на базе ModernBERT) **один полный прогон сети = один шаг денойзинга**. Внутренние слои (l20, l30) выполняют вычисления, оптимальные для денойзинга, а не для синтаксического парсинга токена.
- Проекторы `feat_proj_20` (1024d → 3584d) и `feat_proj_30` существовали исключительно для сопоставления с промежуточными слоями учителя. Задача архитектурно бессмысленна для диффузионной сети.
- Конкурирующий градиентный сигнал от L_state/L_delta на l20/l30 мешал сходимости на l40.

## Decisions Made and Lessons Learned

- **Что не работает:** Принуждение промежуточных диффузионных слоев мимикрировать промежуточные слои LLM — архитектурно некорректная задача, ведущая к расходованию ёмкости сети и деградации геометрии l40.

- **Успешное решение (Best Practice):**
  1. **Полное удаление** `feat_proj_20` и `feat_proj_30`.
  2. **`layer_mapping` сокращается до `{40: 28}`** — только финальный выход сравнивается с учителем.
  3. **Сохранение `raw_student_states[20/30/40]`** — для `cov_loss` (изотропии) на сырых BERT-векторах (1024d) без проекции.
  4. **Вес регуляризации для l20/l30**: `lambda=0.02` (vs `0.1` для l40) — стабилизация геометрии, а не оптимизация.

## Impact

**Позитивное:**
- Освобождение ~2/3 конкурирующего градиентного сигнала, концентрация на l40.
- Экономия VRAM: исключение двух проекторов 1024→3584.
- Архитектурная согласованность: ответствует природе Conditional Latent Diffusion.
- Ожидается снижение `val/l40_cov_loss`, стабилизация `val/l40_isotropy`.

**Негативное / компромиссы:**
- Потеря прямого наблюдения alignment промежуточных слоев (но оно и так не работало).
- Веса `feat_proj_20/30` из старых чекпоинтов игнорируются при загрузке (`strict=False`). Риска для `feat_proj_40` и студента нет.
