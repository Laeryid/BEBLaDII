# ADR 031: Phase 3 — Обучение OutputProjector через Soft Dictionary Matching

## Context and Problem

После завершения Phase 2 (обучения DUSModel и InputProjector) пространство L40 (выход 40-го слоя ModernBERT-large после DUS) стало центрированным, около-сферическим, с rank1_ratio ~0.7. Задача Phase 3 — обучить OutputProjector (MLP 1024→2048→1024→3584), который отображает векторы L40 обратно в пространство Qwen (3584d), необходимое для финального декодирования.

Прямая дистилляция (L40 → выход учителя) невозможна, так как учитель (DeepSeek-R1-Distill-Qwen-7B) заморожен и его выход зависит от конкретного входного контекста, а нам нужно обобщённое отображение пространств.

## Decisions Made and Lessons Learned

### Архитектура решения: Soft Dictionary Matching

Вместо дистилляции с учителя вводится **словарное разложение**. Логика:

**1. Словари формируются заранее из Phase 2:**
- `D_L40.pt` — N репрезентативных векторов L40 (якоря в пространстве студента), N ≈ 50k токенов
- `D_X0.pt` — соответствующие N векторов Qwen X0 (желаемые цели в пространстве Qwen)
- `D_L40_norm.pt` — нормализованные версии D_L40 для косинусного поиска

**2. Soft-разложение (on-the-fly в цикле обучения):**
```
L40_norm = normalize(L40_flat)          # нормируем запрос
scores = (L40_norm @ D_L40_norm.T) / τ  # косинусное сходство / температура
α = softmax(topk(scores, k=28))         # мягкие веса top-k соседей
Z_hat_raw = Σ αᵢ · D_X0[i]            # взвешенная смесь Qwen-векторов
Z_hat = normalize(Z_hat_raw) · Σ αᵢ · ||D_X0[i]||  # восстанавливаем амплитуду
```

**3. Цель обучения — OutputProjector учится предсказывать Z_hat:**
```
Z_pred = OutputProjector(L40_ctx)
loss = HuberLoss(Z_pred, Z_hat_target)
```

### Ключевые метрики качества разложения

- **k_eff** (эффективное k): `exp(H(α))`, где `H` — энтропия Softmax. Показывает, насколько равномерно веса распределены по k соседям. Целевой диапазон: **2–8** (острое семантическое разложение). Значение близкое к k (28) означает вырожденное равномерное распределение.
- **top1_self**: средняя доля веса, приходящаяся на ближайшего соседа. Целевое значение: >0.5.

### Данные для обучения

Пре-токенизированные parquet-файлы (колонка `input_ids`, без токенизатора в цикле обучения):
- `magpie.parquet` — 50k инструкций на рассуждение (EN)
- `openthoughts.parquet` — 50k chain-of-thought (EN)
- `culturax_ru.parquet` — 25k текстов (RU)
- `culturax_cs.parquet` — 25k текстов (CS)

Всего: 150k сэмплов. Якорный токен `<|thought|>` добавляется в начало каждого чанка.

### Инфраструктура

- Обучение: TPU v4, XLA SPMD, `torch_xla.MpDeviceLoader`
- DataLoader: `IndexedParquetDataset.shuffle(rg_buffer=32)` — последовательное чтение row-groups, случайный порядок внутри буфера из 32 групп
- Qwen `embed_tokens` загружается отдельно (не вся модель), DUSModel заморожен
- Чекпоинты и словари: `gs://bebladii-datasets-us/phase 3/`

## Impact

- OutputProjector обучается без учителя в цикле — только на основе словарного разложения
- Качество разложения (k_eff) критически зависит от изотропии пространства L40 и температуры τ
- Метрика top1_self позволяет диагностировать коллапс в argmax-режим
