# ADR 011: Оптимизация архитектуры проекторов (Learnable Scale)

**Дата:** 2026-05-09
**Статус:** Принято
**Контекст:** Фаза 1 Дистилляции.

## Проблема

В ходе мониторинга обучения Фазы 1 было замечено, что MSE (Mean Squared Error) для промежуточных слоев (особенно `l30_mse`) застыл на высоких значениях (3.0–15.0) при целевом показателе < 0.1. Анализ показал, что:
1. `FeatureProjector` оканчивается `LayerNorm`, который принудительно нормализует дисперсию выхода до 1 (норма вектора $\approx \sqrt{3584} \approx 59$).
2. Целевые активации учителя (Qwen/DeepSeek) имеют среднюю норму $\approx 24$.
3. Резидуальная ветка `residual_proj` из-за инициализации (std=0.02) имеет норму $\approx 15$.
4. Возникает "масштабный барьер": проектор не может сжать свои активации до уровня учителя, не теряя при этом информативность направления, из-за жесткой нормализации.

## Решение

Внедрение обучаемого масштабирования (`learnable output_scale`) в `FeatureProjector`.

1. **Механизм:** Добавлен параметр `self.output_scale` (размерность `output_dim`), инициализированный значением `0.1`.
2. **Применение:** Масштаб применяется к результату MLP-ветки (`proj`) *до* суммирования с резидуальной веткой.
   ```python
   out = self.proj(x) * self.output_scale
   return out + res
   ```
3. **Логика:** Это позволяет сети самостоятельно выучить оптимальный баланс между нормализованным выходом MLP и линейным shortcut, а также подогнать итоговую норму под масштаб учителя (~24) без борьбы с `LayerNorm`.

## Последствия

1. **Снятие "стеклянного потолка":** Ожидается возобновление снижения MSE после плато.
2. **Мониторинг:** В WandB добавлены метрики `train/scale_l20`, `train/scale_l30`, `train/scale_l40` для отслеживания динамики адаптации масштаба (ожидаемый рост с 0.1 до ~0.4).
3. **Совместимость:** Новые параметры инициализируются корректно при загрузке старых чекпоинтов через `strict=False` в `load_state_dict`.
4. **Рестарт:** Рекомендован рестарт обучения с шага 0 (с сохранением весов модели) для корректного прогрева нового параметра и сброса состояний оптимизатора Adafactor.
