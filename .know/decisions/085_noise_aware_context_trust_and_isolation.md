# ADR 085: Noise-Aware Context Trust and Isolation (Phase 4)

## Context
В Phase 4 (Hierarchical Noise) используется AdaLN для модулирования слоя LayerNorm перед QKV-проекцией. K-векторы зашумленных токенов отличаются от чистых. Однако текущий базовый градиент (`L_cosine`) обучал модель только предсказывать правильный токен, не давая обратной связи о том, из-за какого именно контекста (какого соседа) произошла ошибка. Если чистый токен ошибается из-за шумных соседей, градиент не направлял сеть к тому, чтобы "изолироваться" от этих шумных ключей внимания. Это могло приводить к "заражению" чистых токенов галлюцинациями из зашумленного контекста.

## Decision
Внедрена стратегия **Noise-Aware Context Trust**, состоящая из следующих компонентов:

1. **Curriculum Батчирование (Сэмплирование типов)**:
   Обучение начинается с 1-го этапа, где батчи жестко разделены на крайние ситуации для выработки нужной логики:
   - **Type A1** (20%): Абсолютный якорь (Остров). Токены преимущественно шумные, но есть 1-3 абсолютно чистых якоря. Цель: якоря должны предсказываться верно, несмотря на шум соседей.
   - **Type A2** (20%): Относительный якорь (Остров). В очень шумном контексте (t ≈ 0.7+) случайные 1-3 токена получают умеренный шум (t ≈ 0.3-0.5). Цель: научить модель полагаться на менее зашумленные токены.
   - **Type B** (40%): Море чистоты. Контекст очень чистый, но есть 1-3 очень шумных выброса. Цель: модель не должна позволять шумным выбросам заражать чистых соседей.
   - **Type C** (20%): Старый иерархический шум со строгим условием — ложно-уверенные токены (false confident) создаются *только* если уровень шума соседей достаточно низок (ctx_noise < 0.4).

2. **Замена L_cosine на L_weighted**:
   Равномерное взвешивание токенов было заменено на `L_weighted`, где ошибка токена взвешивается обратно пропорционально его задекларированному шуму: `w = (1 - t_reported)^alpha_weighted` (alpha_weighted = 1.5). Чистые токены получают больший вес, заставляя сеть агрессивнее их защищать.

3. **Внедрение L_isolation**:
   Добавлен специальный штраф `L_isolation` (lambda_iso = 0.5), который дополнительно увеличивает лосс для чистого токена (относительного или абсолютного), если его контекст сильно зашумлен:
   `penalty = loss_el * (1 + beta_iso * ctx_noise) * clean_mask * attn_f`
   `ctx_noise` рассчитывается через свертку `Conv1d` (окно = 11). Мягкая маска (сигмоида) плавно отключает это слагаемое для заведомо шумных токенов.

## Consequences
- Градиент от ошибки на чистом токене потечет через `Q·K^T` в `K`-векторы соседей (пропущенные через AdaLN). Модель напрямую научится понижать веса внимания к шумным ключам, формируя геометрический механизм недоверия.
- Формирование `Context Isolation Score` (отладка в evaluation скрипте, <0.05 целевой) для принятия решения о переходе на Этап 2 (где пропорция сдвинется к 60% Type C).
- Гарантируется сохранение предыдущих архитектурных решений (x0-prediction, float32 precision, отсутствие блендинга).
