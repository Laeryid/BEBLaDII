# ADR 060: Переход к канонической диффузии на сфере (Phase 3 Redesign)

## Context and Problem

Текущий план Phase 3 (зафиксированный в `experiments/phase3/plan.md`) был спроектирован исходя из ошибочного понимания диффузионного обучения. Конкретные проблемы:

1. **Фиксированный LowNoiseAmp:** Модель обучалась только на малых уровнях шума — последний шаг диффузии. Она учится «дочищать» почти готовые векторы, опираясь на соседние чистые токены. Глобальное Score Field (векторное поле притяжения по всей сфере) не формируется.

2. **Частичное зашумление токенов:** Когда зашумляется только часть фразы, модель учится читерить: восстанавливать шумный токен по чистым соседям, а не по Score Field. На инференсе (где все токены — шум) она теряется.

3. **Confidence Embedding как механизм передачи t:** Вектор `c_embed` (bounded norm=0.1, ADR-047) используется как кондиционирование по уровню шума. Это слабый и непрямой механизм: информация о `t` поступает через первый токен или аддитивно, а не через нормализацию активаций каждого блока.

4. **Следствие:** Результатом обучения по текущему плану является **контекстуальный латентный фильтр** (ближе к MLM в непрерывном пространстве), а не диффузионная модель. Фазы 4–10 плана предполагают рабочую диффузию как фундамент — текущий план его не создаёт.

**Источник инсайта:** Дискуссия с Gemini («Математика диффузии.md»), в которой были разобраны математические основы диффузии на гиперсфере (броуновское движение, фон Мизес-Фишер, Denoising Score Matching, Score Field).

## Decisions Made and Lessons Learned

### Что не работало
- **LowNoiseAmp + частичные токены** → MLM-подобный фильтр, не способный генерировать с нуля.
- **Попытка объединить денойзинг и дистилляцию учителя** → конфликт градиентов (ADR-042, ADR-049).
- **c_embed как кондиционирование по t** → Shortcut Collapse при больших нормах (ADR-047), слабый сигнал при bounded norm.

### Успешное решение (Best Practice)

**Phase 3 переопределяется как безусловная каноническая диффузия на гиперсфере.**

Цель фазы: DUS выучивает глобальное Score Field над латентным пространством LatentEncoder (Qwen-сфера, d=1024). Без промпта. Без дистилляции учителя. Чистая геометрия языка.

#### Ключевые изменения архитектуры:

**1. Полный диапазон шума (Cosine Schedule):**
- Для каждого сэмпла в батче сэмплируется `t ∈ [0, 1]` по косинусному расписанию.
- Параметр концентрации: `κ(t) = κ_max · (1 - cos(t · π/2))^(-1)` (или через `μ_t = cos(t · π/2)`).
- При `t→0`: κ→∞, шума нет. При `t=1`: κ=0, равномерное распределение на сфере.
- В пространстве d=1024 линейное расписание неприемлемо: вектор срывается в полный шум за первые 20% шагов из-за концентрации меры (проклятие размерности).

**2. Зашумление всех токенов фразы:**
- Все токены фразы получают одинаковый уровень шума `t` (сэмплированный единожды для фразы).
- Зашумлённый вектор: `x_t = slerp(x_0, ε, t)`, где `ε ~ Uniform(S^{d-1})`.
- Это единственный способ научить модель работать из состояния «всё — шум».
- `c_embed` полностью удаляется.

**3. AdaLN для кондиционирования по t:**
- В каждый блок DUS добавляется `AdaLN_modulation: nn.Linear(t_emb_dim, 2 * hidden_dim)`.
- Инициализация: `weight=0, bias=[0...0, 1...1]` → при старте `scale=1, shift=0` → нулевое влияние на существующие веса.
- Временной эмбеддинг: `SinusoidalEmbedding(t) → MLP → t_emb`.
- Применение: `AdaLN(x, t) = scale(t) ⊙ LayerNorm(x) + shift(t)`.

**4. Функция потерь (x0-prediction):**
- DUS предсказывает чистый вектор `x_0` из зашумлённого `x_t`.
- Loss: `L = 1 - <DUS(x_t, t), x_0>` (Cosine Similarity Loss).
- Геометрический лосс (prior_loss, cov_loss) на последнем слое — сохраняется.
- MSE/Huber не используется: на сфере метрика угловая, а не евклидова.

**5. Сохранение существующих весов:**
- Веса DUS из чекпоинта Phase 2/3 полностью переносятся.
- AdaLN инициализируется нейтрально — не нарушает стартовое поведение модели.
- Первые шаги обучения: AdaLN «молчит», модель адаптируется к новому расписанию шума.

#### Новая структура фаз:

| Фаза | Было | Стало |
|---|---|---|
| **Phase 3** | LowNoiseAmp, частичные токены, c_embed, дистилляция (удалена ADR-049) | **Безусловная диффузия**, полный `t`, все токены, AdaLN |
| **Phase 4** | Latent Decoder Bridge | **Условная диффузия** (CA_Prompt включается), CFG |
| **Phase 5+** | CLM Pooling | Без изменений (CLM, Memory, Context) |

### Почему это работает математически

По теореме Denoising Score Matching (Vincent, 2011): обучение предсказывать `x_0` из `x_t` на случайных `t` по всему диапазону эквивалентно обучению глобальному Score Field `∇ log p(x_t)`. Именно это поле обеспечивает самокоррекцию при многошаговой генерации.

«Умность» (логические рассуждения) выучится **неявно** — чтобы восстановить сильно зашумлённый токен в контексте фразы, сеть обязана понять связи между токенами. Это тот же механизм, что работает в DiT/Stable Diffusion 3.

## Impact

- **Позитивный:** Модель получит реальное Score Field → сможет генерировать с нуля → Phase 4–10 становятся работоспособными.
- **Позитивный:** Удаление c_embed упрощает архитектуру. Конец истории с Shortcut Collapse.
- **Позитивный:** AdaLN — прямой и математически корректный механизм кондиционирования по `t`. Совместим с DiT-паттерном.
- **Позитивный:** CFG (Classifier-Free Guidance) в Phase 4 требует безусловного prior — Phase 3 его создаёт.
- **Негативный (принятый):** Требуется рефакторинг `train_phase3_logic.py`: добавление AdaLN в DUS-блоки, синусоидального t-эмбеддинга, косинусного расписания, логики полного зашумления.
- **Негативный (принятый):** Существующий чекпоинт `step_5995` несовместим по архитектуре (отсутствует AdaLN). Требуется миграция весов с нейтральной инициализацией новых слоёв.
