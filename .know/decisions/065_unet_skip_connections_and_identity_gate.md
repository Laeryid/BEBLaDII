# ADR 065: UNet-style Skip-Connections и Identity Gate(t) для DUS

## Context and Problem

В ходе анализа (сессия 2026-07-27) была зафиксирована фундаментальная проблема: **DUS на основе ModernBERT структурно не способен выучить тождественное преобразование** при `t -> 0`.

Корневые причины:

1. **Pre-LN + Residual Stream**: ModernBERT использует `x_out = x + Attn(LayerNorm(x))`. Тождественность достигается только если `Attn(LayerNorm(x)) -> 0` одновременно для всех 40 слоёв. Это крайне маловероятный аттрактор для pretrained весов.

2. **DUS Overlap (слои 8-19 дублированы)**: Одни и те же блоки ModernBERT обрабатывают вектор дважды подряд, удваивая самоинтерференцию. Тождественность требует, чтобы эти блоки дважды подряд выдавали нулевой delta, что невозможно без специальной инициализации.

3. **t=0 отсутствует в обучающей выборке**: Косинусное расписание шума κ(t) сдвигает распределение в сторону высокого шума. Режим `t ≈ 0` (тождественность) практически не встречается в батчах.

4. **Предыдущие попытки**:
   - `c_embed` (ADR-047, bounded norm=0.1) — слишком слабый сигнал; Shortcut Collapse.
   - AdaLN нулевой инициализации (ADR-064) — нулевые градиенты 7000+ шагов.
   - `scale = t*s(t)` в AdaLN (рассмотрено, отклонено): при совмещении с gate даёт двойное затухание t^2 и слабый сигнал при t < 0.3.
   - Внешний `gate(t)` без внутреннего t-кондиционирования — сеть не знает t, не понимает разницу между t=0.1 и t=0.9.

## Decisions Made and Lessons Learned

- **Что не сработало:**
  - `c_embed` как сигнал тождественности (ADR-047) — Shortcut Collapse.
  - Нулевая инициализация AdaLN (ADR-064) — нулевые градиенты 7000+ шагов.
  - `scale = t*s(t)` в AdaLN (рассмотрено, отклонено): двойное затухание t^2 при совмещении с gate, слабый AdaLN при средних t.
  - Внешний `gate(t)` без внутреннего t-кондиционирования — сеть не понимает уровень шума.

- **Успешное решение (Best Practice):**

  ### Схема: Внешний Gate(t) + обычный AdaLN

  ```
  x_t (noisy) --> DUS(x_t, t) [AdaLN полностью активен] --> h_39
       |                                                        |
       +---------- skip (x_t передаётся напрямую) -------------+
                                                                |
                                                                v
                        x_out = gate(t) * h_39 + (1 - gate(t)) * x_t
  ```

  **Gate**: `gate(t) = t` (или `sin(t * pi/2)` для более плавного перехода).

  - При `t=0`: `x_out = 0 * DUS(x_0) + 1 * x_0 = x_0` — тождество структурно гарантировано.
  - При `t=1`: `x_out = 1 * DUS(noise) + 0 * noise = DUS_pred ≈ x_0` — полное предсказание.

  ### Разделение ответственностей AdaLN и Gate

  AdaLN и gate выполняют **разные** функции:
  - **AdaLN**: передаёт сети информацию о *силе шума* — кондиционирование. Должен работать в полную силу при любом t, чтобы сеть понимала, какую коррекцию нужно сделать.
  - **Gate(t)**: управляет *вкладом предсказания* в выход — identity enforcer. Пропорционально t ослабляет вклад DUS, когда состояние уже близко к x_0.

  Объединение `scale = t*s(t)` + gate создаёт двойное затухание (t * t = t^2) — крайне слабый сигнал при t < 0.3.

  ### Совместимость с Оркестратором

  Ограниченность DUS при малом t (gate -> 0) не является проблемой: это **корректное диффузионное поведение**. Оркестратор, обнаруживая низкую уверенность при малом t, поднимает t (re-noisify) и запускает новый шаг деноизинга. Gate обеспечивает согласованность: малый t = «мало что нужно менять» → малый вклад DUS.

  ### Замечание по распределению шума

  t сэмплируется не равномерно по уровню шума: косинусное расписание κ(t) сдвигает распределение в сторону высокого шума. Большинство обучающих примеров приходится на область t ∈ [0.3, 0.9], где gate(t) активен и DUS получает хорошие градиенты. Область t ≈ 0 намеренно разрежена — тождественность там обеспечена структурно (gate), а не обучена.

  ### Регуляризация AdaLN (Защита от 1D вырождения)

  Для предотвращения коллапса модуляции AdaLN в одно измерение внедрена двухкомпонентная регуляризация (`total_div_loss`):
  1. **Межслойное временное разнообразие (All-layer Temporal Diversity)**: Штраф за совпадение выходов AdaLN при разных $t$, вычисляемый по усреднённым векторам по всем 40 слоям DUS (вместо 0-го слоя).
  2. **Канальная изотропизация (Channel-wise Variance Floor)**: Штраф на вырождение дисперсии вдоль скрытого измерения $D=1024$:
     $$\text{channel\_var\_loss} = \sum \text{ReLU}\left(\frac{1}{D} - \text{Var}_D(\text{shift/scale})\right)$$
     Защищает векторы `shift` и `scale` от стягивания 1024 элементов в одинаковую константу (скалярную нормализацию).

## Impact

- **Позитивный:** Тождественное преобразование при `t=0` гарантировано структурно без изменения внутренностей ModernBERT и без хаков AdaLN.
- **Позитивный:** AdaLN сохраняет полноценное кондиционирование на t при всех значениях t — чистое разделение обязанностей.
- **Позитивный:** Защита AdaLN от межслойного и канального 1D вырождения через сочетание временного `div_loss` и канального `var_floor`.
- **Позитивный:** Стандартный паттерн DiT с output blending — математически изученный и стабильный.
- **Позитивный:** Совместимость с Оркестратором: gate semantically aligned с логикой «уверенность = (1-t)».
- **Негативный (принятый):** DUS получает ослабленный градиент пропорционально gate(t) при малых t. Компенсируется: при малых t задача тривиальна (x_t ≈ x_0), потери и так малы, слабый градиент уместен.
- **Требует реализации:** Добавление skip-connection (проброс x_t) и gate-слоя на выходе DUSModel (`BEBLaDIIPhase3.forward()`). Обновление `compute_adaln_diversity_loss()`.
