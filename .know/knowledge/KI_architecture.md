# KI: Architecture (System 1 / 2)

## Основная концепция
BEBLaDII — это архитектура, разделяющая инференс на две системы:
1. **Discrete Verbal Space (System 1)**: Классическая, "быстрая" система, работающая с токенами (Tokenizer, Text Decoder). Переводит сырой текст в векторы и обратно.
2. **Continuous Latent Space (System 2)**: Основное "думающее" ядро. Работает не с дискретными токенами, а с непрерывным распределением векторов на сфере (латентной геометрией). Диффузионный процесс позволяет модели итеративно переосмысливать контекст.

## Модули System 2

1. **Diffusion Backbone (latentBERT)**
   - Выполняет DUS (Depth Up-Scaling) и денуазинг.
   - Обучается работать с индивидуальным уровнем шума для каждого токена (Phase 4).

2. **Sensor Ensemble (Фаза 5)**
   - Главным итогом Фазы 5 стало изучение различных метрик и сигналов, подходящих для управления ходом диффузии, и обучение MLP для части из них. Этот комплексный модуль оценки состояния токена заменил простую `Confidence Head`.
   - Включает в себя:
     - Обучаемую нейросеть `ConfidenceHead` (оценивает внутреннюю уверенность модели, согласованность и сложность на основе сырых амплитуд `h39`).
     - Геометрические метрики: `RawDProx` (сходство с ближайшим словом), `Delta` (разница между топ-1 и топ-2), `ConflictSim` (внутреннее сходство между двумя кандидатами).
   - Защищает Оркестратор от прямого обращения к словарю строк (работает полностью в математическом пространстве).

3. **Orchestrator**
   - Полностью алгоритмический (необучаемый) центр принятия решений.
   - Используя цифры от Sensor Ensemble, решает судьбу каждого токена:
     - Продолжить диффузию (`DENOISING`).
     - Токен готов, заморозить (`CRYSTALLIZED`).
     - Семантический тупик — требуется внешняя помощь (`SEMANTIC_CONFLICT`).
     - Игнорировать синтаксический шум (`SYNTAX_VARIATION`).

4. **Complementary Latent Memory (CLM)**
   - Долгосрочная или оперативная память. В случае семантических тупиков Оркестратор обращается к CLM через слои Cross-Attention (`CA_Memory`, `CA_Context`), инжектируя точные знания (RAG) прямо в латентное пространство без перевода в текст.
