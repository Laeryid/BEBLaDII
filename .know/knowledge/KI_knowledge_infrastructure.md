# KI: Knowledge Infrastructure (Техническая реализация)

## Обзор
Техническое ядро системы управления знаниями, обеспечивающее сбор метрик, отслеживание изменений кода и предоставление интерфейса для ИИ-агентов через MCP.

## Ключевые компоненты
| Класс / Функция | Файл | Назначение |
|---|---|---|
| `KnowledgeEngine` | `scripts/knowledge_engine.py` | Ядро: расчет хешей, сравнение состояний и маппинг изменений на KI. |
| `KnowledgeManager` | `scripts/knowledge_mcp.py` | Реализация MCP-сервера с инструментами `audit_coverage`, `save_state` и др. |
| `AuditCoverage` | `scripts/audit_coverage.py` | Расчет матрицы покрытия, плотности документации и выявление слепых зон. |
| `KIDependencyAnalyzer` | `scripts/ki_dependency_analyzer.py` | Анализ импортов (Python/TS) для автоматического связывания KI в `Related KIs`. |

## Технические детали
- **Механизм хеширования**: Используется SHA-256. Для оптимизации проверка хеша выполняется только если `mtime` (время модификации) файла в системе новее, чем в `doc_state.json`.
- **Блочное чтение**: Файлы читаются блоками по 4096 байт для минимизации потребления памяти при хешировании больших дампов.
- **Изоляция (Jailhouse)**: Все файловые операции через MCP-сервер принудительно ограничиваются корнем `.know/`. Любые попытки доступа через `../` пресекаются на уровне валидации путей.
- **Авто-маппинг (Restore Mapping)**: Функция `restore_mapping` сканирует Markdown-файлы KI на наличие путей в формате `` `path/to/file` `` и автоматически обновляет секцию `depends_on` в `doc_config.json`.

## Ограничения и защита
- **Запрет на запись**: Через MCP-инструменты `write_know_file`/`edit_know_file` категорически запрещено изменять любые файлы вне `.know/` (особенно `.py`, `.bat`).
- **Исключения (EXCLUDE)**: Система игнорирует служебные директории: `.git`, `__pycache__`, `node_modules`, `venv`, `.venv`, `dist`, `build`.

## Типичные проблемы
- **Hash Mismatch**: Если файл был изменен внешней программой, сохраняющей старый `mtime`, система может пропустить изменение. В таких случаях используйте принудительный `save_state`.
- **Regex Limitations**: Авто-маппинг распознает пути только в определенных корневых папках (app, ui, scripts и т.д.). Новые корневые папки нужно добавлять в регулярное выражение в `knowledge_engine.py`.
