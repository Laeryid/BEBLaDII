# KI: RAG Engine

## Что это
Retrieval-Augmented Reasoning (RAG) / Complementary Latent Memory (CLM) — система внешней памяти, работающая напрямую в латентных координатах диффузионного пространства. Позволяет модели динамически извлекать факты и семантические аттракторы в процессе итеративного рассуждения.

> [!NOTE]
> Текущий статус: **Проектирование**. Код в `src/beb_la_dii/rag/` находится на ранней стадии (заглушки в `__init__.py`). Подробная математическая спецификация сжатия чанков и иерархического Cross-Attention вынесена в [`KI_clm_geometric_pooling.md`](KI_clm_geometric_pooling.md).

## Концептуальные компоненты (План)
| Компонент | Локация (план) | Назначение |
|---|---|---|
| **RAG-pooling (`bilinear_chunk_pool`)** | `src/beb_la_dii/rag/pooling.py` | Сжимает окно из $w$ латентных векторов в пару $(s_b, c_b)$: абелево среднее содержания $s_b$ и параметр-фри кососимметричную свёртку внутреннего порядка $c_b$ через `rotate_half` (см. `KI_clm_geometric_pooling.md`). |
| **Latent Index** | `storage/index/` | Векторное хранилище сжатых чанков в пространстве диффузии с двухкритериальным сферическим поиском $[\sqrt{\alpha}\hat{s}, \sqrt{1-\alpha}\hat{c}]$. |
| **CA Layers (`CAMemoryLayer`)** | `src/beb_la_dii/model/diffusion_blocks.py`| Слои Cross-Attention для подмешивания контекста памяти: сочетают макро-RoPE между блоками памяти и микро-порядок $c_b$ внутри блока. |
| **Gamma Gate** | - | Обучаемый вентиль (Gate), определяющий долю влияния внешнего знания. |

## Ожидаемые детали реализации
- **Латентные чанки со сжатием в $w=4\text{–}8$ раз**: В отличие от классического RAG, система оперирует сжатыми блоками латентных векторов $(s_b, c_b)$, сохраняющими внутренний порядок слов без необходимости переиндексации при обучении весов `CA_Memory`.
- **Динамический запрос**: Запрос к RAG инициируется Оркестратором при обнаружении `SEMANTIC_CONFLICT` на диффузионном холсте и сжимается симметричным механизмом $(s_q, c_q)$.
- **Интеграция**: Вставка CA-слоев параллельно основным блокам энкодера с размороженными буферными слоями DUS после инъекции (ADR 095, ADR 097).

## Типичные ошибки (Предупреждения)
- **Синхронизация индексов**: Критически важно, чтобы векторы в `Latent Index` вычислялись детерминированно (через замороженный энкодер и параметр-фри `rotate_half`), без участия обучаемых весов `CA_Memory`.
- **Semantic Drift**: Использование RAG на ранних этапах обучения может "отравить" латентное пространство шумом из памяти. Подключается после стабилизации базовой диффузии (Phase 4 / Phase 6).
