# KI: Knowledge Management (Процессы и стандарты)

## Обзор
Методология ведения базы знаний проекта. Система объединяет архитектурные решения (ADR), операционные инструкции (Workflows) и автоматизированный аудит покрытия для поддержания высокого качества контекста.

## Ключевые процессы
| Процесс | Инструмент/Путь | Описание |
|---|---|---|
| **ADR (Decisions)** | `decisions/` | Фиксация архитектурных решений. Каждый файл — это неизменяемая запись о выборе и его причинах. |
| **Workflows** | `workflows/` | Исполняемые инструкции для агентов. Определяют порядок действий для типовых задач (напр., `/sync-knowledge`). |
| **Audit & Quality** | `audit_coverage()` | Регулярная проверка "свежести" и плотности документации. Выявляет слепые зоны. |
| **Manifest Management** | `doc_config.json` | Декларативное описание связей между знаниями и кодом. |

## Стандарты документации (KI)
Каждый Knowledge Item должен содержать:
1. **last_verified**: Дата последней проверки актуальности.
2. **Overview**: Краткая суть модуля.
3. **Key Components**: Таблица основных классов/функций и их файлов.
4. **Non-obvious Details**: Нюансы, которые нельзя понять просто из сигнатур функций.
5. **Common Pitfalls**: Известные грабли и способы их решения.

## Метрики качества
- **Density (Плотность)**: Отношение объема документации к объему отслеживаемого кода. Целевое значение > 50.0 B/KB.
- **Complexity (Сложность)**: Если один KI покрывает более 10 файлов, он подлежит разделению (🔥).
- **Staleness (Устаревание)**: Если отслеживаемый код изменился, а KI не был обновлен, он помечается как Stale.

## Неочевидные детали
- **Приоритет ADR**: При возникновении конфликта между KI и ADR, ADR (как историческая запись решения) имеет приоритет в объяснении "почему сделано именно так".
- **Связь через doc_config**: Любой новый модуль проекта ОБЯЗАН быть зарегистрирован в `doc_config.json` для включения в цикл аудита.

## Типичные ошибки
- **Manual Edit Desync**: Правка `doc_config.json` вручную без последующего `save_state` приводит к ложным срабатываниям Stale-статуса.
- **Vague Summary**: Слишком краткое описание в `doc_config.json` снижает эффективность поиска контекста агентом.
