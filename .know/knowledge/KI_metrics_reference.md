# KI: Metrics Reference (Phase 2 Distillation)

Исчерпывающий справочник всех метрик, логируемых в `train_phase1_TPU_fsdp.py` и `loss.py`.
**КРИТИЧЕСКИ ВАЖНО:** Многие метрики — это значения ФУНКЦИИ ПОТЕРЬ (LOSS), а не метрики качества.
Рост такой метрики = ухудшение; снижение = улучшение. Не перепутай.

---

## Архитектура пространств

Перед метриками — понимание, на каких данных они считаются:

| Пространство | Размерность | Что это |
|---|---|---|
| `raw_student_l40` | 1024d | Сырой выход 40-го слоя DUS (BERT-space). **Основное многообразие диффузии.** |
| `projected_student_l40` | 3584d | После `feat_proj_40`: 1024d → 3584d (Qwen-space). Для сравнения с учителем. |
| `teacher_l40` | 3584d | Выход 28-го слоя DeepSeek-R1/Qwen (замороженный учитель). |

Метрики на `raw` vs `projected` — принципиально разные сущности.

## Блок 1: Train Loss / Оптимизационные сигналы

> **Тип:** `LOSS`. Логируются с префиксом `train/`. Берутся с варианта полной маски (`idx=3`, `full_`).

### `train/full_l40_cos`
```
cos_l = 1.0 - cosine_similarity(centered(projected_student), centered(teacher))
```
- **Тип:** LOSS (Pearson correlation loss). Диапазон [0, 2], практически [0, 1].
- **В обучении:** `cos_weight=0.0` → **НЕ ОБУЧАЕТСЯ**. Только диагностика.
- **Интерпретация:** Значение 0.984 → реальная Pearson-корреляция = **0.016** (случайно).
- ⚠️ Близость к 1.0 — норма, не достижение.

### `train/full_l40_scale_align`
```python
scale_l = MSE(per_token_std(projected_student), per_token_std(teacher))
```
- **Тип:** LOSS. Единицы — квадрат стандартного отклонения (Qwen-space, 3584d).
- **В обучении:** `lambda_scale=0.1` → **ОБУЧАЕТСЯ**.
- **Интерпретация:** MSE разброса токенов студента vs учителя. Значения ~3–4 означают сильное несоответствие масштаба.
- **Хорошо:** близко к 0.

### `train/full_l40_prior`
```python
prior_loss = m_state.pow(2).mean()      # центрирование (μ → 0)
           + (v_state - 1.0).pow(2).mean()  # дисперсия → 1
           + 0.1 * cov_loss             # изотропия
```
- **Тип:** LOSS. Регуляризация raw l40 к N(0,1).
- **В обучении:** `lambda_prior=0.5` (train) / `0.1` (val) → **ОБУЧАЕТСЯ**.
- **Хорошо:** близко к 0. Спайки → нестабильность геометрии.

### `train/full_l40_cov_loss`
```python
cov_loss = cov_off_diag.pow(2).sum() / D
# cov = (Z^T @ Z) / N  (VICReg-style), Z — центрированные токены
```
- **Тип:** LOSS. Штраф за корреляцию между измерениями (анти-коллапс).
- **В обучении:** Входит в `prior_loss` с коэффициентом `0.1`. Для l20/l30 отдельно с `0.1`.
- **Хорошо:** снижается. Высокие значения (>100) → паттерн схлопывания.

### `train/full_l40_rkd_raw` (Centered RKD)
```python
# Векторы центрируются по батчу с учетом маски перед нормированием (ADR-025)
s_centered = (raw_student - s_mean_rkd) * attention_mask
t_centered = (teacher - t_mean_rkd) * attention_mask

s_normed = s_centered / s_centered.norm(dim=-1, keepdim=True).clamp(min=1e-6)
t_normed = t_centered / t_centered.norm(dim=-1, keepdim=True).clamp(min=1e-6)

s_dist = bmm(s_normed, s_normed.transpose(1, 2))  # (B,T,T) попарные сходства
t_dist = bmm(t_normed, t_normed.transpose(1, 2))  # (B,T,T) попарные сходства
rkd_l  = MSE(s_dist, t_dist.detach())            # с учетом маски mask_2d
```
- **Тип:** LOSS. Относительное сходство пар токенов на **центрированных** векторах (студент vs учитель).
- **В обучении:** `lambda_rkd=0.01` → **ОБУЧАЕТСЯ** (предотвращает Rank-1 коллапс).
- **Интерпретация:** Заставляет студента выучивать геометрию и взаимное расположение кластеров без имитации огромного абсолютного смещения учителя (что ломало `l40_prior` и ужимало изотропию).
- **Хорошо:** снижается. Временный рост RKD лосса сразу после перезапуска с Centered RKD — ожидаем (модель перестраивает распределение).

### `train/full_l40_norm_corr_raw`
```python
s_norms = raw_student_1024d.norm(dim=-1)     # (B, T) — нормы токенов
t_norms = teacher_3584d.norm(dim=-1)          # (B, T) — нормы токенов учителя
norm_l  = 1.0 - Pearson_corr(s_norms, t_norms, per_sequence)
```
- **Тип:** LOSS (1 - Pearson). Диапазон [0, 2], практически [0, 1].
- **В обучении:** `lambda_norm=0.05` → **ОБУЧАЕТСЯ**.
- **Интерпретация:**
  - `0.0` → идеальное совпадение паттерна нормы токенов с учителем
  - `1.0` → нулевая корреляция
  - `>1.0` → **ОТРИЦАТЕЛЬНАЯ корреляция** (хуже случайного!)
- ⚠️ Значение 1.08 = реальный Pearson = **−0.08**. Это ухудшение, не улучшение!

### `train/full_norm_cv_l40_raw` / `val/norm_cv_l40_raw`
```python
# Коэффициент вариации (CV) норм токенов студента на активных токенах
CV = std(active_norms) / mean(active_norms)
```
- **Тип:** METRIC. Диагностика сферичности латентного пространства.
- **Интерпретация:**
  - Показывает разброс длин векторов (норм) токенов студента.
  - `CV < 0.05` (менее 5% вариации) означает, что векторы имеют практически одинаковую длину, то есть латентное пространство сошлось к **сферическому многообразию** (Zen Solution).
  - Если `CV > 0.10` перед запуском фазы диффузии (Phase 8), это указывает на то, что пространство представляет собой шаровой слой ненулевой толщины, и нам может потребоваться явная нормализация векторов или адаптация noise schedule.
- **Хорошо:** Близко к `0.0` (полная сферичность).

### `train/full_lXX_intermediate_reg` (l20, l30)
```python
intermediate_loss = m_state.pow(2).mean()   # центрирование
                  + 0.1 * cov_loss           # ортогонализация
                  + 0.1 * soft_var_penalty   # soft clamp дисперсии
```
- **Тип:** LOSS. Суммарный регуляризатор промежуточных слоев (не привязан к учителю, ADR-019).
- **В обучении:** вес `1.0` → **ОБУЧАЕТСЯ**.
- **Хорошо:** снижается. Рост после LR-спайка → перестройка геометрии слоя.

### `train/full_lXX_soft_var_penalty` (l20, l30)
```python
soft_var_penalty = F.relu(v_state - 1.5).pow(2).mean()
```
- **Тип:** LOSS. Мягкий ограничитель дисперсии — не штрафует пока `σ² < 1.5` (ADR-023).
- **Хорошо:** 0 (дисперсия в норме). Рост → дисперсия превысила 1.5.

## Блок 2: Train Trajectory / Delta-метрики

> **Тип:** `METRIC` (не loss). Реальные значения сходства. Три перехода: `t01`, `t12`, `t23`.

### `train/delta_cos_l40_tXY`
```python
ds = mean_pool(student[mask_Y]) - mean_pool(student[mask_X])
dt = mean_pool(teacher[mask_Y]) - mean_pool(teacher[mask_X])
dcos = cosine_similarity(ds, dt).mean()
```
- **Тип:** METRIC. Реальное косинусное сходство направлений изменения пространства.
- **Диапазон:** [−1, 1]. **Выше = лучше.**
- **Интерпретация:** Насколько студент движется в том же семантическом направлении, что и учитель, при переходе от варианта маски X к Y.
- ⚠️ Значения 0.08–0.18 — очень низкое совпадение (почти случайное).

### `train/delta_mag_ratio_l40_tXY`
```python
dmag = (ds.norm(dim=-1) / dt.norm(dim=-1).clamp(min=1e-6)).mean()
```
- **Тип:** METRIC. Отношение магнитуд дельты студента к дельте учителя.
- **Идеал:** ~1.0. Ниже 1.0 → студент "шевелится" меньше, выше 1.0 → больше.

### `train/l_state_total`
- Суммарный L_state по 4 вариантам масок с весами MASK_WEIGHTS.

### `train/l_delta_total`
- Суммарный L_delta по 3 переходам (без gamma). Используется для мониторинга.

### `train/gamma`
- Текущий вес L_delta: `min(0.5, 0.3 + step/10000 * 0.2)`. Растёт с 0.3 до 0.5 за 10k шагов.

## Блок 3: Val Heavy Metrics / Геометрические метрики пространства

> **Тип:** `METRIC` (не loss). Считаются на первом валидационном батче (только активные токены). SVD-тяжёлые.

### `val/l40_isotropy`
```python
_, s, _ = torch.linalg.svd(centered_raw_1024d)
isotropy = (s.sum()**2) / (len(s) * (s**2).sum())
```
- **Тип:** METRIC. Индекс изотропии: **`1.0`** = идеально изотропное, **`1/N ≈ 0.001`** = чистый rank-1.
- **Диапазон:** [0, 1]. **Выше = лучше.**
- **Интерпретация:** Насколько равномерно распределена дисперсия по всем измерениям.
- Значение 0.047 → один компонент несёт в ~21× больше дисперсии, чем среднее.

### `val/l40_rank1_ratio`
```python
rank1 = (s[0]**2) / (s**2).sum()
```
- **Тип:** METRIC. Доля дисперсии в первом главном компоненте.
- **Диапазон:** [0, 1]. **Ниже = лучше.**
- Значение 0.82 → 82% всей дисперсии сконцентрировано в одном направлении (тяжёлый коллапс).

### `val/l40_projected_isotropy` / `val/l40_projected_rank1_ratio`
- То же самое, но на projected 3584d пространстве. Диагностика проектора.

### `val/l40_mu_drift`
```python
mu = raw_1024d.mean(dim=0)   # (D,)
mu_drift = mu.pow(2).mean()
```
- **Тип:** METRIC. Среднеквадратичное отклонение среднего от нуля по измерениям.
- **Диапазон:** [0, ∞). **Ниже = лучше.** Идеал: 0.

### `val/l40_var_drift`
```python
var = raw_1024d.var(dim=0, unbiased=False)  # (D,)
var_drift = (var - 1.0).pow(2).mean()
```
- **Тип:** METRIC. Среднеквадратичное отклонение дисперсии от 1.0 по измерениям.
- **Диапазон:** [0, ∞). **Ниже = лучше.** Идеал: 0.

### `val/l40_neighbor_recall`
```python
# N=256 случайных токенов (только активные, 1024d студент vs 3584d учитель)
s_sim = normalize(student_1024d) @ normalize(student_1024d).T  # (N, N)
t_sim = normalize(teacher_3584d) @ normalize(teacher_3584d).T  # (N, N)
recall = mean(|top-5(s_sim[i]) ∩ top-5(t_sim[i])| / 5)
```
- **Тип:** METRIC. Совпадение топ-5 соседей студента с учителем (cross-space).
- **Диапазон:** [0, 1]. **Выше = лучше.**
- ⚠️ **Random baseline ≈ 0.10** (5 из ~255 случайно). Значение 0.17 — лишь на 70% выше случайного.
- Это межпространственное сравнение (1024d vs 3584d): потолок может быть ниже 1.0.

### `val/l40_ns_sigma_X_X`
```python
noise = randn_like(raw_1024d) * sigma
ns = (1 - cosine_similarity(raw_1024d, raw_1024d + noise)).mean()
```
- **Тип:** METRIC. Чувствительность пространства к гауссовому шуму при σ ∈ {0.1, 0.3, 0.5, 1.0}.
- **Диапазон:** [0, 1]. **Ниже = стабильнее пространство к шуму.** Ключевая метрика для диффузии.

## Блок 4: Val Standard Metrics

> Усредняются по всем валидационным батчам.

| Метрика WandB | Формула | Тип | Хорошо |
|---|---|---|---|
| `val/loss` | Полный total_loss на val (lambda_prior=0.1) | LOSS | ↓ |
| `val/l40_cos` | = `full_l40_cos` (Pearson loss, cos_weight=0) | LOSS (disabled) | Диагностика |
| `val/l40_scale_align` | = `full_l40_scale_align` | LOSS | ↓ |
| `val/l40_prior` | = `full_l40_prior` | LOSS | ↓ |
| `val/l40_cov_loss` | = `full_l40_cov_loss` | LOSS | ↓ |
| `val/rkd` / `val/l40_rkd_raw` | = `full_l40_rkd_raw` | LOSS | ↓ |
| `val/norm_corr` / `val/l40_norm_corr_raw` | = `full_l40_norm_corr_raw` (1−Pearson) | LOSS | ↓ (0 = идеал) |

## Быстрая шпаргалка (опасные интерпретации)

| ❌ Частая ошибка | ✅ Правда |
|---|---|
| `val/l40_cos = 0.98` → "хорошее выравнивание" | LOSS = 0.98 → alignment = **2%**, cos_weight=0, не обучается |
| `val/norm_corr = 1.08` → "выше 1 — отлично" | LOSS **>1.0** → Pearson = **−0.08** (хуже случайного!) |
| `val/norm_corr` растёт → "улучшение" | **УХУДШЕНИЕ**, это loss |
| `val/l40_neighbor_recall = 0.17` → "17% — плохо" | Baseline случайного = 0.10; относительно +70%, но всё равно низко |
| `val/l40_isotropy` и `rank1_ratio` — оба "выше = лучше" | Нет: isotropy ↑ хорошо, rank1_ratio ↑ **плохо** |
| `delta_cos` — это loss | Нет, это реальное сходство направлений (выше = лучше) |
