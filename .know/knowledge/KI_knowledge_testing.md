# KI: Knowledge Infrastructure Testing

## Overview
Система автоматизированного тестирования инфраструктуры знаний. Проверяет корректность расчета покрытия, безопасность MCP-сервера и стабильность генерации индексов.

## Key Components

### Integration Tests
| File | Purpose | Details |
|---|---|---|
| `test_knowledge_engine.py` | Тест ядра. | Валидация хеширования, обнаружения изменений и маппинга файлов на KI. |
| `test_audit_coverage.py` | Тест аудита. | Проверка корректности расчета Density, обнаружения Blind Spots и генерации матрицы. |
| `test_mcp_security.py` | Тест безопасности. | Проверка ограничений (Jailhouse): попытки выхода за пределы `.know/` и записи в запрещенные файлы. |

### Utility Tests
| File | Purpose | Details |
|---|---|---|
| `test_generate_dir_index.py` | Тест индексации. | Проверка глубины сканирования и корректности отображения дерева папок. |
| `test_sync_and_add_ki.py` | Тест управления. | Валидация процессов добавления новых KI и синхронизации с `doc_config.json`. |

## Non-obvious Details
- **Mocking Filesystem**: Тесты используют временные директории для создания фиктивных проектов, чтобы не влиять на основную базу знаний при проверке логики удаления или перезаписи.
- **Security Scenarios**: `test_mcp_security.py` включает сценарии с использованием путей типа `../../etc/passwd` (для Linux-эмуляции) и `..\..\config.py` для подтверждения изоляции.

## Common Pitfalls
- **State Pollution**: Если тест падает до очистки временных файлов, следующие запуски могут выдавать ошибки из-за "грязного" состояния. Рекомендуется использовать фикстуры `pytest` с автоматической очисткой.
- **Symlink Handling**: Тесты инфраструктуры знаний на Windows могут вести себя иначе с симлинками. Большинство тестов их игнорирует.
